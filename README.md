# Network Engineering Projects in Cisco Packet Tracer

This repository contains hands-on networking projects created in **Cisco Packet Tracer** as I showcase and build my skills as an aspiring **Network Engineer**, or Network Security Engineer.

The projects focus on practical networking concepts such as:

- Various network topology design
- IPv4 addressing and subnetting
- VLANs and trunking
- Inter-VLAN routing
- Static and dynamic routing
- DHCP and DNS
- Access Control Lists (ACLs)
- Switch and router configuration
- Network troubleshooting and connectivity testing
- and more

Each project will include configuration steps, Cisco IOS commands, topology details, and explanations of how the network works.

## Goal

My goal is to demonstrate practical experience designing, configuring, securing, and troubleshooting networks while documenting my progress as a CCNA holder.

## Tools

- Cisco Packet Tracer
- Cisco IOS CLI
- GitHub
